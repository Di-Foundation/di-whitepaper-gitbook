$Di is the ecosystem-consumptive token within the DI ecosystem.

It connects real product usage, AI service consumption, compute service quotas, data and model contributions, Agent collaboration, and ecosystem governance into an economic loop.

$Di is designed to provide a unified economic medium for service usage, resource input, contribution collaboration, and governance participation inside the DI ecosystem.

## Ecosystem Positioning

$Di serves consumption and collaboration inside the DI ecosystem.

Users can use $Di for AI event simulation, Compute Packs, developer APIs, Agent services, model services, data services, and enterprise intelligence modules. Ecosystem contributors can submit contributions around high-quality data, model optimization, Agent building, historical event review, risk identification, and developer tools, then enter the contribution evaluation and incentive process. Governance participants can collaborate around ecosystem rules, contribution standards, task templates, product parameters, and resource allocation.

The core function of $Di is to connect three types of behavior: service consumption, contribution incentives, and ecosystem governance.

## Service Consumption

$Di can be used for multiple service consumption scenarios inside DI:

- Event Engine event simulation tasks;
- AI Quant Intelligence research tasks;
- Compute Packs;
- API Services developer calls;
- Model Services calls;
- Agent Access and specialized Agent usage;
- Enterprise Intelligence services;
- data services, report generation, and task templates.

Users can also pay with stablecoins to lower the access barrier. Stablecoin payments form part of DI's operating resource inflow and may support product building, compute input, model iteration, data procurement, ecosystem collaboration, and long-term operations.

As $Di ecosystem access capabilities gradually open and usage scenarios mature, DI will strengthen $Di's native role in service consumption, ecosystem incentives, and governance collaboration.

## Contribution Incentives

$Di will be used to incentivize real contributions inside the DI ecosystem.

Incentivized contributions can include high-quality data, effective models, stable Agents, historical event reviews, risk identification, security feedback, developer tools, task templates, enterprise integration, ecosystem education, and community building.

DI will use contribution quality, verifiability, long-term value, and system improvement as incentive criteria.

## Ecosystem Governance

$Di will gradually participate in DI ecosystem governance.

Governance scope focuses on internal ecosystem matters, including contribution rules, data standards, model evaluation, Agent access, Compute Pack types, API permissions, ecosystem incentives, task templates, and risk-control parameters.

The goal is to allow long-term participants in DI's construction to collaborate on ecosystem evolution.

## Economic Loop

$Di's economic loop comes from real service demand and ecosystem contribution.

Users consume DI products. Service consumption drives demand for compute, models, data, and Agents. Ecosystem contributors provide data, models, Agents, reviews, and tools around these needs. The system improves overall capability through contribution incentives and governance collaboration.

This loop connects $Di with DI product usage, resource input, and ecosystem collaboration.
