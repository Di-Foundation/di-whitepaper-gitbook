## Product Entrances

DI has four product entrance types.

The first type is intelligent products for end users and research users, including Event Engine and AI Quant Intelligence. Event Engine enables users to launch event simulations and receive structured intelligence outputs. AI Quant Intelligence turns events, on-chain data, market variables, and historical samples into researchable, backtestable, and monitorable objects.

The second type is capability entrances for developers and advanced users, including API Services and Compute Packs. API Services open event intelligence, risk scores, asset impact matrices, and Agent workflows. Compute Packs turn underlying compute into small, purchasable, executable, and consumable service quotas.

The third type is enterprise service, Enterprise Intelligence. It combines DI's event intelligence, quantitative research, APIs, data services, and Agent workflows into enterprise dashboards, risk monitoring systems, research reports, and internal workflows.

The fourth type is the long-term ecosystem collaboration network, including contributions around data, models, agents, historical reviews, and developer tools.

Together, these entrances form DI's AI + Crypto intelligence ecosystem.

DI's early beachhead will focus on three high-value user groups. The first group is crypto researchers, trading teams, and risk teams that need event simulation, risk identification, market structure analysis, and research production. The second group is Web3 projects and institutional customers that need project risk monitoring, event alerts, sentiment analysis, enterprise reports, and customized dashboards. The third group is developers and AI builders that need APIs, Compute Packs, data services, model capabilities, and Agent tools.

At the early stage, DI will focus on high-frequency needs in crypto markets: event intelligence, risk analysis, research production, and developer access.

## Ecosystem Direction

DI starts from event simulation and quantitative research, then expands into a broader AI + Crypto intelligence ecosystem. Event Engine and AI Quant Intelligence are core application scenarios. DI's long-term direction is to build an open ecosystem around real compute, native data models, Agent coordination, developer services, and Web3 contribution mechanisms.

In this ecosystem, users consume AI services, developers call APIs and Compute Packs, researchers build event and quantitative analysis workflows, data contributors provide high-quality data, model contributors improve vertical capabilities, Agent builders create specialized agents, and institutions access enterprise intelligence services.

DI connects these roles so AI capability becomes callable, extensible, and collaborative intelligence infrastructure for crypto markets.
