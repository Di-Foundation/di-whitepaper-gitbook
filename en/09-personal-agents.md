# 9. Personal Agents

Personal Agents are DI’s next stage after product launch. They will connect data, simulation and quant capabilities around a user’s ongoing tasks, allowing users to build and configure their own financial Agent teams.

## Ongoing work for the same user

Users differ in the assets, research topics, time horizons and tasks they care about. A Personal Agent is intended to organize work within that context and help follow changes without requiring the user to restate the entire task each time.

For example, a user may follow an event and its implications for a group of assets. The Agent can organize relevant information, assist with renewed research as conditions change and call the required product capabilities.

## Calling products according to the task

| Task requirement | Capability |
| --- | --- |
| Discover changes and organize information | Data Dashboard |
| Examine scenarios, perspectives and evidence | Event Engine |
| Research strategies, review or create products | Quant Platform |

A task can combine several capabilities or use just one. The Personal Agent organizes them while keeping the user’s context together across stages.

## Preferences and permissions

A Personal Agent should work within the scope chosen by its user. Monitoring information, conducting research and taking actions involving assets have different consequences and require appropriate task boundaries and permissions.

This whitepaper describes Personal Agents as an interface for authorized tasks. It does not assume unlimited automated trading permissions or prescribe a custody model. Available tools and actions depend on the product functionality and authorization interface.

## Connecting to the network

Personal Agents will participate in the future Agent network. They will be able to call data, research and strategy capabilities across the network and, within authorized boundaries, provide information or capabilities to other Agents.

Personal Agents and a cross-user network are separate development stages. The first supports a user’s ongoing work; the second expands the scope of collaboration.
