Developer and Ecosystem Layer is DI's open ecosystem layer for external developers, researchers, projects, data providers, model builders, Agent builders, and enterprise customers.

This is DI's external building layer. Developers can call DI's event intelligence, risk scores, asset impact matrices, and Agent workflows through API Services. They can execute training, inference, data processing, backtesting, and Agent experiments through Compute Packs. They can access structured data and model capabilities through Data Services and Model Services. They can build new vertical Agents through Agent Access.

API Services are for capability calls. Compute Packs are for task execution. Data Services and Model Services open underlying capabilities. Agent Access supports ecosystem expansion.

## Why Developer and Ecosystem Layer Is Needed

AI + Crypto use cases are broad. A single team cannot cover all vertical needs.

Trading teams may need event monitoring and risk alerts. Research institutions may need data analysis and report generation. Security teams may need on-chain abnormality detection and attack tracking. Web3 projects may need project risk monitoring and market feedback analysis. Developers may need APIs, compute packs, and Agent tools. Quant teams may need backtesting, factor generation, and market structure data. Enterprise customers may need customized event intelligence and dashboards.

DI opens its underlying capabilities so the ecosystem can build on top of them.

## Open Capabilities

API Services allow developers and institutions to call DI capabilities through interfaces. APIs can cover event structuring, event simulation, risk scoring, asset impact matrices, on-chain anomaly detection, market structure monitoring, sentiment analysis, historical event retrieval, quantitative variable generation, and Agent workflow calls.

Data Services provide standardized data services, including on-chain data, market structure data, historical event data, project data, sentiment data, and macro variable data. These are cleaned, structured, tagged, and model-enhanced data services.

Model Services expose part of DI's crypto-native model capability as model services. Developers and partners can call model capability under specific permissions for event understanding, semantic analysis, risk identification, historical similar-event retrieval, market structure judgment, and research assistance.

Agent Access will gradually open Agent access capability. External developers can build specialized Agents based on DI's Agent framework, such as stablecoin risk agents, exchange reserve monitoring agents, RWA research agents, DeFi risk agents, NFT and GameFi narrative agents, Layer2 data agents, security event agents, and multilingual sentiment agents.

Compute Packs provide low-barrier compute services for developers and small teams. Developers can use Compute Packs to run inference, training, data processing, backtesting, Agent experiments, and batch API tasks.

Task Templates provide standardized task templates that help developers and users quickly start common tasks, including event simulation, on-chain anomaly monitoring, stablecoin risk monitoring, exchange risk monitoring, historical event backtesting, quant factor research, Agent workflows, and enterprise report generation.

Enterprise Intelligence is DI's managed intelligence service for institutional customers, trading teams, Web3 projects, security teams, and enterprise users. It can combine Event Engine, AI Quant Intelligence, API Services, data services, and Agent workflows into customized dashboards, risk monitoring systems, event alert modules, research report systems, and internal enterprise workflows.

Unlike API Services for developers, Enterprise Intelligence emphasizes managed delivery, permission management, customized data sources, continuous monitoring, dedicated reports, and enterprise integration.

## Ecosystem Participants

Developers can build applications, plugins, dashboards, automation tools, and vertical products based on DI's APIs, Compute Packs, data services, and Agent framework.

Researchers can use DI's data, models, Event Engine, and AI Quant Intelligence for event research, market structure analysis, historical review, and risk evaluation.

Data contributors can provide high-quality on-chain labels, project data, historical event annotations, risk event records, sentiment data, and market structure data.

Model contributors can contribute models, algorithms, indicators, or evaluation methods for specific directions to improve DI's event understanding, risk identification, and market analysis.

Agent builders can develop new specialized Agents to expand DI's capabilities across sectors, chains, markets, and languages.

Enterprise customers can integrate DI's event intelligence, risk analysis, data services, and APIs into their research, risk-control, or operating systems.

## Ecosystem Loop

The value of Developer and Ecosystem Layer is to expand DI from a product system into an open ecosystem.

DI provides compute, data, models, Agents, and product capabilities. External participants build tools, applications, and services on top of these capabilities. These tools and services increase DI's use cases, data feedback, contribution quality, and ecosystem value.
