Real compute capacity is DI's foundational capability.

DI's AI services require continuous access to real compute for model inference, data processing, Agent concurrency, historical retrieval, backtesting, training, and report generation.

In DI, compute is transformed into a capability that can be used by products, developers, and the broader ecosystem.

## Tasks Supported by Compute

DI's real compute capacity mainly supports:

- Event Engine simulations and scenario modeling;
- Agent Network parallel task execution;
- inference and updates for the 800TB crypto-native model;
- factor research, backtesting, and market structure analysis for AI Quant Intelligence;
- small-scale training, inference, data processing, and Agent experiments for Compute Packs;
- batch calls and developer workflows for API Services;
- customized reports, monitoring, and risk-control tasks for Enterprise Intelligence.

These tasks all require stable, schedulable, and scalable compute resources.

## Productized Compute

DI turns complex server, GPU, and cloud scheduling capacity into product capabilities that users can understand and use.

For ordinary users, compute is embedded inside Event Engine and AI Quant Intelligence. Users start a task, and the system completes calculation, model calls, and Agent coordination in the background before returning reports, matrices, indicators, or dashboards.

For developers and advanced users, DI provides Compute Packs. Each Compute Pack corresponds to specific task capabilities, such as inference, training, data processing, backtesting, Agent experiments, or batch API calls. Users consume service quotas as tasks are completed.

This divides large-scale compute capacity into smaller, clearer, and easier-to-use service units.
