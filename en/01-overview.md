# 1. DI Overview

DI (Decentralized Intelligence) is building a user-owned financial Agent network. Built on a Crypto-native Model, DI connects data discovery, event research and quantitative products. Its development path takes users from individual tools to their own financial Agents, and then to collaboration across an interconnected network.

## Starting with products

DI has three connected product capabilities:

| Product | Question it addresses | What users receive |
| --- | --- | --- |
| Data Dashboard | What is happening, and which changes deserve attention? | Market data, news, social perspectives and research leads to follow |
| Event Engine | How might an event develop, and what supports the analysis? | Multi-perspective discussion, evidence, process receipts and a research report |
| Quant Platform | How can a strategy become a usable product? | DI quant products, strategy creation tools and a product marketplace |

The products connect around the same research subjects, sources and judgment conditions. A user can discover an event in the dashboard, examine its implications in Event Engine, and use quant tools to test and express a strategy. This is an iterative process: new data can change an event assessment, while strategy results can raise new research questions.

## From Personal Agents to a network

After product launch, DI will connect these capabilities through Personal Agents. Working with user preferences and permissions, an Agent will monitor markets, organize research and call tools, reducing the need for users to carry out every step manually.

The next stage will establish the first Agent network with seed users from 2,000 founding NFTs. Agents belonging to different users will exchange information, call capabilities and collaborate on tasks. DI’s long-term goal is to connect each user’s Agent team to data, research and strategies across the network.

Descriptions of those stages express the development direction and do not mean that network functionality is already available.
