DI's model foundation is a crypto-native model built on 800TB of crypto-native data.

Crypto markets have their own language, structure, and behavioral patterns. General models can understand some public text, but they do not naturally master wallet behavior, protocol mechanisms, exchange structures, stablecoin systems, DeFi composability, project life cycles, social narratives, and macro linkages.

The 800TB crypto-native model is built for this environment.

## Data Scope

The model data covers multiple dimensions:

- On-chain data: address behavior, transfer paths, fund flows, protocol interactions, contract events, wallet labels, and abnormal behavior;
- Market data: prices, volume, depth, order books, funding rates, open interest, liquidation data, and volatility;
- Project data: protocol mechanisms, token economics, governance records, team information, financing information, ecosystem relationships, and product progress;
- Event data: historical regulatory events, exchange risk events, security incidents, stablecoin events, macro events, project crises, and market shocks;
- Sentiment data: social media, community discussions, KOL narratives, news coverage, and emotion changes;
- Macro data: dollar liquidity, interest rates, inflation, risk asset performance, geopolitics, and policy changes;
- Security data: vulnerabilities, attacks, phishing, abnormal addresses, hacker fund flows, and protocol risks.

These data sources are cleaned, structured, tagged, and enhanced by models to form DI's native market context.

## Model Value

The 800TB crypto-native model enables DI to understand relationships behind complex events.

When a user asks an event question, the system can retrieve similar information from historical events, on-chain behavior, market structure, asset correlations, sentiment changes, and macro environments, then organize Agents for multi-dimensional analysis.

The model provides not only text understanding but also crypto market context. It helps DI judge which variables are relevant, which paths may transmit risk, which assets may be affected, which indicators are worth monitoring, and which risks require continuous tracking.

## Integration With Agent Network

The model provides knowledge and reasoning foundations. Agent Network turns model capability into executable workflows.

Event parsing agents can use the model to understand event types. On-chain analysis agents can combine address and fund-flow data to detect abnormalities. Market structure agents can analyze liquidity and leverage. Sentiment agents can track narrative diffusion. Quantitative research agents can turn event variables into research indicators. Report generation agents can integrate multi-dimensional outputs into user-readable results.

The 800TB crypto-native model is not a standalone data asset. It is a core foundation for DI's intelligence ecosystem.
