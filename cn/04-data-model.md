# 4. 数据与 Crypto-native Model

Crypto-native Model 是 DI 各类产品共同使用的模型基础。它围绕加密市场中的资产、事件、叙事与行为组织信息，为发现问题、分析事件和研究策略提供支持。

## 数据覆盖与持续更新

截至 2026 年 10 月 11 日，DI 的来源覆盖包括 **8,000+ 个 X 账号**与 **500+ 个媒体来源**。产品结合实时行情与持续更新的新闻、社交信息，帮助用户从市场变化中发现研究线索。

| 信息类型 | 研究价值 |
| --- | --- |
| 市场行情 | 观察资产价格及市场变化 |
| 新闻与事件 | 确定事件背景、时间和后续发展 |
| 社交观点 | 比较不同叙事、表达和观点分歧 |
| 链上与资产相关信息 | 为市场行为和策略研究补充上下文 |

行情、新闻与社交来源按各自的数据周期更新，覆盖数据用于支持市场发现与持续跟踪。

## 从资料到可使用的上下文

模型与数据基础将资料连接到具体研究对象：事件研究围绕背景、依据与分歧展开，策略研究则围绕变量、假设和结果之间的关系展开。

信息来源仍然是判断的重要部分。模型生成的解释不能取代原始出处，也不能将未经证实的消息自动变成事实。

## 与产品和算力的关系

数据与模型服务于看板、推演和量化工具。计算资源支持信息处理、模型调用和研究任务。
