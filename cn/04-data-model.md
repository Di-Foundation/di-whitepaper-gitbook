# 4. 数据与 Crypto-native Model

Crypto-native Model 是 DI 各类产品共同使用的模型基础。它围绕加密市场中的资产、事件、叙事与行为组织信息，为发现问题、分析事件和研究策略提供支持。

## 数据覆盖与持续更新

截至 2026 年 10 月 11 日，DI 的来源覆盖包括 **8,000+ 个 X 账号**与 **500+ 个媒体来源**。产品结合实时行情与持续更新的新闻、社交信息，帮助用户从市场变化中发现研究线索。

| 信息类型 | 研究价值 |
| --- | --- |
| 市场行情 | 观察资产价格及市场变化 |
| 新闻与事件 | 确定事件背景、时间和后续发展 |
| 社交观点 | 比较不同叙事、表达和观点分歧 |
| 链上与资产相关信息 | 为市场行为和策略研究补充上下文 |

来源覆盖数、累计内容量与模型训练数据量是不同指标。账号数量也不代表独立用户数量。不同来源有不同的更新节奏；实时行情不意味着所有历史资料和社交信息都以同样频率更新。

## 从资料到可使用的上下文

模型与数据基础的作用，是帮助产品将材料连接到具体研究对象。对于事件研究，重要的是相关资料能否解释背景、支持论点、呈现分歧。对于策略研究，重要的是变量、假设与结果之间的关系能否被清楚表达。

信息来源仍然是判断的重要部分。模型生成的解释不能取代原始出处，也不能将未经证实的消息自动变成事实。

## 与产品和算力的关系

数据与模型服务于看板、推演和量化工具。计算资源支持信息处理、模型调用和研究任务，但算力规模本身不等同于研究质量。

本白皮书不以数据体积推断模型参数量、准确率或收益表现。具体模型实现、数据许可、更新范围与服务性能，应以相应技术及产品披露为准。
