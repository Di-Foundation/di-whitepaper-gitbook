真实算力能力是 DI 的底层基础。

DI 的 AI 服务需要持续调用真实算力来完成模型推理、数据处理、Agent 并发、历史检索、回测、训练和报告生成。

在 DI 体系中，算力的价值会被转化为可被产品、开发者和生态使用的能力。

## 算力支撑的任务

DI 的真实算力能力主要支撑以下任务：

- Event Engine 的事件推演与情景模拟；
- Agent Network 的并行任务执行；
- 800TB 原生币圈模型的推理与更新；
- AI Quant Intelligence 的因子研究、回测和市场结构分析；
- Compute Packs 的小型训练、推理、数据处理和 Agent 实验；
- API Services 的批量调用和开发者工作流；
- Enterprise Intelligence 的定制化报告、监控和风控任务。

这些任务都需要稳定、可调度、可扩展的计算资源。

## 产品化算力

DI 将复杂的服务器、GPU 配置和云资源调度能力，转化为用户能够理解和使用的产品能力。

对于普通用户，算力被封装在 Event Engine 和 AI Quant Intelligence 中。用户发起任务，系统在后台完成计算、模型调用和 Agent 协作，最终输出报告、矩阵、指标或 API 结果。

对于开发者和高阶用户，DI 提供 Compute Packs。每个算力包对应具体任务能力，例如推理、训练、数据处理、回测、Agent 实验或 API 批量调用。用户按任务使用，任务完成后额度被消耗。

这种方式将大型算力能力拆分为更小、更清晰、更容易使用的服务单元，降低个人用户和小团队的使用门槛。

## 算力与智能生态的关系

算力是 DI 的底座，也是 DI 产品能力持续运行的基础。

只有当算力与原生数据、模型、Agent 和产品场景结合时，才能形成真实用户价值。DI 的算力能力嵌入事件推演、量化研究、开发者服务、企业智能和生态贡献机制中。

这也是 DI 与单纯算力叙事的区别：DI 的核心是将真实算力能力转化为加密市场中的智能生产力。
