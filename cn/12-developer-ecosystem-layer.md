Developer & Ecosystem Layer 是 DI 面向外部开发者、研究员、项目方、数据方、模型方、Agent 构建者和企业客户开放的生态层。

这一层是 DI 的外部构建层。开发者可以通过 API Services 调用 DI 的事件智能、风险评分、资产影响矩阵和 Agent 工作流；通过 Compute Packs 执行训练、推理、数据处理、回测和 Agent 实验任务；通过 Data Services 与 Model Services 获取结构化数据和模型能力；通过 Agent Access 构建新的垂直 Agent。

API 负责能力调用，Compute Packs 负责任务执行，Data Services 与 Model Services 负责底层能力开放，Agent Access 负责生态扩展。这一层的目标，是让更多开发者和生态参与者能够基于 DI 构建工具、插件、Agent、分析面板、研究模块、企业级系统和垂直应用。

## 为什么需要开发者与生态层

AI + Crypto 的应用场景非常广泛，单一团队很难覆盖所有垂直需求。

交易团队可能需要事件监控和风险预警；研究机构可能需要数据分析和报告生成；安全团队可能需要链上异常识别和攻击追踪；Web3 项目方可能需要项目风险监控和市场反馈分析；开发者可能需要 API、算力包和 Agent 工具；量化团队可能需要回测、因子生成和市场结构数据；企业客户可能需要定制化事件智能和仪表盘。

因此，DI 将开放底层能力，让 DI 从产品前端扩展为可被外部构建的生态能力。

## 开放能力

API Services 允许开发者和机构通过接口调用 DI 的能力。API 可以覆盖事件结构化、事件推演、风险评分、资产影响矩阵、链上异常检测、市场结构监控、舆情分析、历史事件检索、量化变量生成和 Agent 工作流调用。

Data Services 提供标准化的数据服务，包括链上数据、市场结构数据、历史事件数据、项目数据、舆情数据和宏观变量数据。这些数据不是简单原始数据堆叠，而是经过清洗、结构化、标签化和模型增强的数据服务。

Model Services 将 DI 的 crypto-native model 以模型能力服务的形式开放。开发者和合作方可以在特定权限下调用模型能力，用于事件理解、语义分析、风险识别、历史相似事件检索、市场结构判断和研究辅助。

Agent Access 将逐步开放 Agent 接入能力。外部开发者可以基于 DI 的 Agent 框架构建自己的专业 Agent，例如稳定币风险 Agent、交易所储备监控 Agent、RWA 研究 Agent、DeFi 风险 Agent、NFT 与 GameFi 叙事 Agent、Layer2 数据 Agent、安全事件 Agent 和多语言舆情 Agent。

Compute Packs 为开发者和小团队提供低门槛算力服务。开发者可以使用 Compute Packs 运行推理、训练、数据处理、回测、Agent 实验和 API 批量任务，而不需要自行部署复杂算力基础设施。

Task Templates 提供标准化任务模板，帮助开发者和用户快速启动常见任务。模板可以覆盖事件推演、链上异常监控、稳定币风险监控、交易所风险监控、历史事件回测、量化因子研究、Agent 工作流和企业报告生成。

Enterprise Intelligence 是 DI 面向机构客户、交易团队、Web3 项目方、安全团队和企业级用户提供的托管式智能服务。它可以将 Event Engine、AI Quant Intelligence、API Services、数据服务和 Agent 工作流组合为定制化仪表盘、风险监控系统、事件预警模块、研究报告系统和企业内部工作流。

与面向开发者的 API Services 不同，Enterprise Intelligence 强调托管交付、权限管理、定制数据源、持续监控、专属报告和企业级集成能力。

## 生态参与者

开发者可以基于 DI 的 API、Compute Packs、数据服务和 Agent 框架构建应用、插件、仪表盘、自动化工具和垂直产品。

研究员可以使用 DI 的数据、模型、Event Engine 和 AI Quant Intelligence 进行事件研究、市场结构分析、历史复盘和风险评估。

数据贡献者可以提供高质量链上标签、项目数据、历史事件标注、风险事件记录、舆情数据和市场结构数据。

模型贡献者可以贡献特定方向的模型、算法、指标或评估方法，用于提升 DI 的事件理解、风险识别和市场分析能力。

Agent 构建者可以开发新的专业 Agent，扩展 DI 在不同赛道、不同链、不同市场和不同语言环境中的能力。

企业客户可以将 DI 的事件智能、风险分析、数据服务和 API 集成到自己的研究、交易、风控或运营系统中。

## 生态循环

Developer & Ecosystem Layer 的价值，在于将 DI 从产品体系扩展为开放生态。

DI 提供底层算力、数据、模型、Agent 和产品能力；外部参与者基于这些能力构建更多工具、应用和服务；这些工具和服务反过来增加 DI 的使用场景、数据回流、贡献质量和生态价值。
