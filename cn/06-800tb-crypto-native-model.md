DI 的模型底座，是基于 800TB 原生币圈数据构建的 crypto-native model。

加密市场有自己的语言、结构和行为模式。通用模型可以理解部分公开文本，但很难天然掌握链上行为、协议机制、交易所结构、稳定币系统、DeFi 组合性、项目生命周期、社交叙事和宏观联动。

DI 的 800TB 原生币圈模型正是为这一场景构建。

## 数据范围

模型数据覆盖多个维度：

- 链上数据：地址行为、转账路径、资金流、协议交互、合约事件、钱包标签和异常行为；
- 市场数据：价格、成交量、深度、订单簿、资金费率、未平仓合约、清算数据和波动率；
- 项目数据：协议机制、代币经济、治理记录、团队信息、融资信息、生态关系和产品进展；
- 事件数据：历史监管事件、交易所风险事件、安全事件、稳定币事件、宏观事件、项目危机和市场冲击；
- 舆情数据：社交媒体、社区讨论、KOL 叙事、新闻报道和情绪变化；
- 宏观数据：美元流动性、利率、通胀、风险资产表现、地缘政治和政策变化；
- 安全数据：漏洞、攻击、钓鱼、异常地址、黑客资金流和协议风险。

这些数据通过清洗、结构化、标签化和模型增强，形成 DI 的原生市场语境。

## 模型价值

800TB 原生币圈模型使 DI 能够理解复杂事件背后的市场关系。

当用户提出一个事件问题时，系统可以从历史事件、链上行为、市场结构、资产相关性、舆情变化和宏观环境中检索相似信息，并组织 Agent 进行多维分析。

模型不仅提供文本理解能力，也提供加密市场上下文。它帮助 DI 判断哪些变量相关，哪些路径可能传导，哪些资产可能受影响，哪些指标值得监控，以及哪些风险需要持续跟踪。

## 与 Agent Network 的结合

模型本身提供知识和推理基础，Agent Network 则负责将模型能力组织成任务流程。

事件解析 Agent 可以调用模型理解事件类型；链上分析 Agent 可以结合地址和资金流数据识别异常；市场结构 Agent 可以分析流动性和杠杆；舆情叙事 Agent 可以捕捉情绪扩散；量化研究 Agent 可以把事件变量转化为可研究指标；报告生成 Agent 可以将多维输出整合成用户可读结果。

因此，800TB 原生币圈模型不是独立展示的数据资产，而是 DI 智能生态持续运行的核心底座。
