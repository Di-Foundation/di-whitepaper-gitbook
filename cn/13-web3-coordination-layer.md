Web3 Coordination Layer 是 DI 用于组织开放协作、记录真实贡献和激励生态建设的协作层。

DI 引入 Web3 机制，是为了让生态中的真实贡献能够被记录、评估、激励和治理。

AI + Crypto 生态的建设，不可能只依赖单一团队完成。高质量数据、模型优化、Agent 构建、历史事件复盘、风险识别、开发者工具和行业研究，都需要更广泛的参与者共同建设。

Web3 Coordination Layer 的作用，就是为这种开放协作提供机制基础。

## 协作对象

数据贡献者可以为 DI 提供高质量数据和标签，包括链上地址标签、交易所钱包标记、稳定币流动数据、协议状态数据、项目基础信息、治理提案记录、安全事件记录、历史事件时间线、舆情内容整理和市场结构数据补充。

模型贡献者可以围绕特定任务提供模型、算法、评估方法或优化方案，包括事件分类模型、风险评分模型、舆情分析模型、链上行为识别模型、资金异常检测模型、稳定币风险模型、交易所风险模型、历史相似事件检索模型和情景生成模型。

Agent 构建者可以为 DI 生态开发专业 Agent，例如稳定币风险 Agent、交易所储备监控 Agent、RWA 研究 Agent、DeFi 风险 Agent、Layer2 数据 Agent、跨链桥安全 Agent、NFT 与 GameFi 叙事 Agent、多语言舆情 Agent、地缘政治 Agent 和监管政策 Agent。

历史复盘贡献者可以围绕历史事件提供事件时间线补充、关键节点标注、市场反应记录、链上数据变化、舆情扩散路径、资产影响分析、风险扩散复盘和事后错误修正。

安全与风险贡献者可以为 DI 提供协议漏洞提示、钓鱼风险识别、钱包异常行为、可疑资金流追踪、交易所风险信号、稳定币风险信号、恶意数据提交识别、Agent 滥用检测和 API 风险反馈。

开发者工具贡献者可以围绕 DI 的 API、Compute Packs、Agent 框架和数据服务构建插件、SDK、可视化面板、数据连接器、自动化工作流、企业集成工具、研究模板、Agent 调试工具和第三方应用。

## 贡献评估

DI 的贡献评估将围绕真实价值展开。

贡献可以根据准确性、可验证性、时效性、稳定性、可复用性、对模型质量的提升、对 Agent 表现的提升、对产品使用体验的提升、对风险识别能力的提升和对生态扩展的贡献进行评估。

DI 将通过贡献评估机制，识别长期高质量贡献者，并持续优化任务分配、权限开放和激励机制。

## 信誉系统

DI 将逐步建立贡献者信誉系统。

信誉系统可以记录贡献者在不同维度上的长期表现，例如数据质量、模型表现、Agent 稳定性、历史复盘有效性、安全贡献、开发者工具使用量、社区评价、争议记录和错误修正表现。

信誉系统将帮助 DI 更好地识别长期高质量贡献者，并提升生态协作效率。

## 生态激励机制

DI 将围绕真实贡献建立生态激励机制。

可被激励的贡献包括高质量数据、有效模型、稳定 Agent、历史复盘、风险识别、安全贡献、开发者工具、企业集成、社区教育和生态应用。

激励机制将重点关注贡献质量、可验证性和长期生态价值，而不是简单任务数量。

## 治理协作

Web3 Coordination Layer 也将支持生态治理协作。

治理范围将聚焦于 DI 生态内部的产品、数据、模型、Agent、Compute Packs、API、贡献规则和风险控制参数。

Web3 Coordination Layer 的目标，是让 DI 从一个产品体系逐步扩展为由用户、开发者、研究员、数据方、模型方、Agent 构建者和生态合作方共同参与的 AI + Crypto 智能生态。
