# 5. 数据看板

数据看板是 DI 的信息发现与持续监测入口。它把行情、媒体报道和社交观点放到同一研究环境中，帮助用户发现值得关注的资产与事件，并继续查看背后的资料。

## 发现与筛选

用户可以围绕资产、市场变化和研究主题浏览信息，通过筛选缩小范围，再将有价值的对象加入关注列表。看板的目的，是降低发现和整理材料的成本，让用户更快知道哪些问题值得进一步研究。

资讯数量或讨论热度本身不构成结论。同一主题下的报道与观点，需要结合时间、出处及市场背景阅读。

## 保留来源

新闻与社交内容应能回到原始资料。用户既可以观察聚合后的变化，也可以查看具体报道和观点，以判断信息是否相关、是否有新的证据，以及是否存在明显分歧。

持续跟踪不只是重复展示一条信息。围绕同一资产或事件，后续资料可以补充、修正或削弱原来的判断。

## 与 Event Engine 和量化平台衔接

看板提供研究线索，Event Engine 将线索展开为问题、情景与讨论。量化工具则支持用户进一步研究规则或选择产品。

例如，用户发现一个资产相关事件后，可以先核对报道与社交反应，再研究它可能影响哪些市场条件。是否将研究转化为策略，取决于用户判断和产品规则。

在个人 Agent 阶段，看板的数据能力将成为持续监测的基础。Agent 可以结合用户偏好组织相关变化，使信息发现成为持续任务的一部分。
