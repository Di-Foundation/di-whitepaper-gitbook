DI 是面向 AI + Crypto 的智能生态。

它由四个核心能力组成：真实算力能力、800TB 原生币圈模型、Agent Network 智能协作层，以及面向用户、开发者和机构的产品与应用层。

真实算力能力提供模型推理、训练、数据处理、回测、Agent 并行任务和 API 调用的底层资源。800TB 原生币圈模型提供加密市场上下文，使系统能够理解链上、市场、事件、舆情、项目和宏观变量。Agent Network 将复杂任务拆解给多个专业 Agent 并行处理。产品与应用层把底层能力转化为 Event Engine、AI Quant Intelligence、Compute Packs、API Services 和 Enterprise Intelligence。

DI 的核心是一个可扩展的智能生态。

## DI 的产品入口

DI 的产品体系可以分为四类入口。

第一类是面向终端用户和研究用户的智能产品，包括 Event Engine 与 AI Quant Intelligence。Event Engine 让用户能够围绕复杂事件发起推演，获得结构化分析和智能输出；AI Quant Intelligence 将事件、链上数据、市场变量和历史样本转化为可研究、可回测和可监控的分析对象。

第二类是面向开发者和高阶用户的能力入口，包括 API Services 与 Compute Packs。API Services 负责开放事件智能、风险评分、资产影响矩阵和 Agent 工作流；Compute Packs 负责把底层算力拆分为可购买、可执行、可消耗的小型服务额度。

第三类是面向机构和项目方的企业级服务，即 Enterprise Intelligence。它将 DI 的事件智能、量化研究、API、数据服务和 Agent 工作流组合为企业级仪表盘、风险监控、研究报告和内部工作流。

第四类是面向生态长期扩展的协作网络，包括数据、模型、Agent、历史复盘和开发者工具贡献。

这四类入口共同构成 DI 的 AI + Crypto 智能生态。

DI 的早期滩头阵地将聚焦三类高价值用户：第一类是 Crypto 研究员、交易团队和风险团队，他们需要事件推演、风险识别、市场结构分析和研究生产工具；第二类是 Web3 项目方和机构客户，他们需要项目风险监控、事件预警、舆情分析、企业级报告和定制化仪表盘；第三类是开发者和 AI 构建者，他们需要 API、Compute Packs、数据服务、模型能力和 Agent 工具来构建新的应用。

在早期阶段，DI 将优先聚焦 Crypto 市场中事件智能、风险分析、研究生产和开发者调用这几个高频需求。

## DI 的生态方向

DI 从事件推演和量化研究出发，逐步扩展为更大的 AI + Crypto 智能生态。Event Engine 和 AI Quant Intelligence 是生态中的核心应用场景，DI 的长期方向，是围绕真实算力、原生数据模型、Agent 协作、开发者服务和 Web3 贡献机制，形成一个开放的 AI + Crypto 智能生态。

在这个生态中，用户可以消费 AI 服务，开发者可以调用 API 和算力包，研究员可以构建事件和量化分析，数据贡献者可以提供高质量数据，模型贡献者可以优化垂直任务，Agent 构建者可以创建专业 Agent，机构和项目方可以接入企业级智能服务。

DI 将这些角色连接起来，使 AI 能力不再停留在单一应用层，而是成为加密市场中可调用、可扩展、可协作的智能基础设施。
