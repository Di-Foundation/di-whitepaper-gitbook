# 1. DI 概述

DI（Decentralized Intelligence）正在构建用户拥有的金融智能体网络。它以面向加密市场的 Crypto-native Model 为基础，将数据发现、事件研究和量化产品连接起来，让用户从使用单个工具，逐步走向拥有自己的金融 Agent，并通过 Agent 与整个网络协作。

## 从产品开始

DI 的产品体系包含三个相互衔接的部分：

| 产品 | 解决的问题 | 用户得到什么 |
| --- | --- | --- |
| 数据看板 | 市场发生了什么，哪些变化值得关注？ | 行情、新闻、社交观点与持续跟踪的研究线索 |
| Event Engine | 一个事件可能怎样发展，判断依据是什么？ | 多视角讨论、证据、过程收据与推演报告 |
| 量化平台 | 如何将策略做成可以使用的产品？ | DI 自有量化产品、策略创建工具与产品市场 |

三类产品共享研究对象、信息来源与判断条件。用户可以从看板发现事件，在 Event Engine 中研究其影响，再通过量化工具检验和表达策略。这个过程允许反复验证：新的数据可以改变事件判断，策略结果也可以提出新的研究问题。

## 从个人 Agent 走向网络

产品上线后，DI 将把这些能力连接到个人 Agent。个人 Agent 根据用户的偏好和授权，持续跟踪市场、组织研究并调用工具，使金融任务不再完全依赖用户逐项操作。

下一阶段，以 2,000 个创始 NFT 对应的种子用户建立首个 Agent 网络。不同用户的 Agent 将能够交换信息、调用彼此的能力并协作完成任务。DI 的长期目标，是让每个用户的智能体团队都能连接网络中的数据、研究与策略能力。
