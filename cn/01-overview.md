## DI Foundation

DI 设有位于新加坡的 DI Foundation。

DI 是一个由真实算力能力与一个基于 800TB 币圈原生数据构建的 crypto-native model 共同支撑的 AI + Crypto 智能生态。

DI 正在构建的是一个面向加密市场、AI 开发者、研究员、机构和 Web3 项目的智能生态：底层由真实算力和原生数据模型支撑，中间由 Agent Network 进行任务协作，上层形成事件推演、量化研究、算力包、API 服务、企业级智能服务和生态协作机制。

加密市场正在变得更加复杂。链上数据、交易所数据、宏观变量、监管变化、地缘政治、稳定币流动性、安全事件、社交舆情和项目基本面共同影响市场行为。传统工具通常只能覆盖其中一部分信息，而用户真正需要的是能够理解复杂事件、组织多维数据、调用模型和算力，并输出结构化判断的智能系统。

DI 的核心定位，是将 AI 能力、真实算力、加密市场数据和 Web3 协作机制连接起来，形成一个可持续演进的 AI + Crypto 智能生态。

DI 的第一个旗舰产品是 Event Engine，即 AI 事件推演引擎。它面向战争、监管、交易所风险、稳定币脱锚、链上安全事件、宏观冲击和市场叙事变化等复杂事件，组织多 Agent 协作团队，结合真实算力和 800TB 原生币圈模型，输出事件推演、风险热力图、资产影响矩阵、关键监控指标和研究报告。

Event Engine 是 DI 生态能力的第一个集中展示场景。围绕底层算力和模型能力，DI 还将扩展 AI Quant Intelligence、Compute Packs、API Services、Enterprise Intelligence、数据与模型贡献机制，以及开发者生态。

DI 的长期方向，是成为加密市场中面向事件、数据、模型、算力和智能协作的 AI + Crypto 智能生态。
