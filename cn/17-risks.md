# 17. 风险与使用说明

DI 提供信息、研究与产品工具。用户需要结合资料来源、产品规则和自身需求判断其适用范围。AI 生成内容、量化策略和 Agent 协作都可能出现错误或损失。

## 数据与模型

资料可能延迟、遗漏、错误或相互矛盾。模型可能生成不准确的解释，也可能过度依赖某类来源。多角色讨论与多 Agent 协作不能保证独立性或正确性。

来源引用和过程收据帮助检查研究，但不能替代对原始证据的判断。事件发生后，原先成立的条件也可能改变。

## 量化产品

策略可能在历史数据中表现良好，却不适用于后续市场。流动性、交易成本、资产集中与极端波动都可能影响实际结果。

动态篮子涉及的 Meme 资产可能有较大的价格与流动性风险。定期调仓、指数型结构和每期额度限制均不保证收益或本金安全。用户创建产品也需要分别评估其规则、表现与风险。

## Agent 与外部能力

个人 Agent 和网络依赖相应工具、数据和服务的可用性。外部服务中断、错误信息或授权范围理解不准确，都可能影响任务结果。

涉及私有信息或资产操作的任务受用户授权与产品规则约束。未经用户授权共享的研究内容保留为私有信息。

## 存证与代币

链上记录可能涉及交易延迟、费用及网络故障。版本凭证用于核验记录，不保证报告真实性、预测准确性或奖励资格。

DI Token 可能面临市场价格与流动性风险。商业收入与回购受实际业务影响，不构成固定收益或价格保证。
