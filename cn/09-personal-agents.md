# 9. 个人 Agent

个人 Agent 是 DI 在产品上线后的下一阶段。它将数据、推演和量化能力连接到同一个用户的持续任务中，让用户逐步拥有可以配置和使用的金融智能体团队。

## 围绕同一个用户持续工作

用户可以有不同的关注资产、研究主题、时间范围和任务偏好。个人 Agent 的设计目标，是在这些上下文中组织工作，帮助用户持续跟踪变化，而不必每次从头说明需求。

例如，用户可以关注某个事件及其对一组资产的影响。Agent 围绕这一任务组织相关信息，在条件发生变化时协助重新研究，并调用所需的产品能力。

## 按任务调用产品

| 任务需要 | 对应能力 |
| --- | --- |
| 发现变化、整理信息 | 数据看板 |
| 研究情景、比较观点与依据 | Event Engine |
| 研究策略、查看或创建产品 | 量化平台 |

一次任务可以组合多种能力，也可以只调用其中一项。个人 Agent 将这些能力组织起来，不要求用户为每个阶段重新建立上下文。

## 用户偏好与授权

个人 Agent 应在用户选择的范围内工作。信息监测、研究分析与涉及资产的操作具有不同影响，需要分别理解用户的权限与任务边界。

本白皮书将个人 Agent 描述为用户授权下的任务入口，不据此假定无限自动交易权限，也不预设具体的资产托管模式。实际开放的工具和操作以产品功能与授权界面为准。

## 连接网络

个人 Agent 是未来 Agent 网络的参与者。它既可以调用网络中的数据、研究与策略能力，也可以在授权范围内向其他 Agent 提供信息或能力。

个人 Agent 的形成与跨用户网络的建立是两个阶段。前者服务于用户的持续任务，后者扩大可协作的范围。
