# DI Whitepaper

DI (Decentralized Intelligence) is building a user-owned financial intelligence network. Its Crypto-native Model connects market data, event research and quantitative tools, with Personal Agents and an interconnected Agent network forming the next stages of its roadmap.

The DI Whitepaper introduces the project's vision, product architecture and economic design. It explains how the Data Dashboard, Event Engine, Quant Platform and Dynamic Baskets fit together, and outlines the role of DI, the business model, development roadmap and risks.
