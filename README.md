# DI Whitepaper

Official source repository for the DI Whitepaper.

DI is an AI + Crypto intelligence ecosystem built on real compute capacity, an
800TB crypto-native model, Agent Network coordination, and a multi-product
application layer.

## Languages

- [English (default)](./en/README.md)
- [简体中文](./cn/README.md)

The GitBook configuration publishes English at `/` and Simplified Chinese at
`/zh`.

## Repository Structure

- `en/`: English whitepaper and English diagrams
- `cn/`: Simplified Chinese whitepaper and Chinese diagrams
- `assets/`: shared DI brand assets
- `docs.yaml`: GitBook site and language configuration
