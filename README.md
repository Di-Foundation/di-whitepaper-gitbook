## Static reader

This repository includes the bilingual source, illustrations and static reader. Build with `npm ci`, `npm run build` and `npm test`. The build generates `dist/` from `en/SUMMARY.md` and `cn/SUMMARY.md`; content changes must update both language summaries and paired chapter filenames.

The public reader is hosted separately at [whitepaper.di.xyz](https://whitepaper.di.xyz/). GitHub content updates are not an automatic production deployment: the release owner imports the reviewed source into the isolated Sites checkout, validates it, then publishes an exact source/archive version. Do not place hosting credentials or secrets in this repository.
